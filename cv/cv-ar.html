نبذة مهنية

مطور Full-Stack بخبرة تتجاوز 3 سنوات في بناء منتجات SaaS متعددة المستأجرين باستخدام Laravel/PHP مع واجهات JavaScript حديثة (React و Inertia.js و Vue.js). مؤسس Azz، وهو تطبيق لزيادة المبيعات على متجر تطبيقات سلة يعمل في أكثر من 1,000 متجر نشط، وبنيت منصات تعمل فعليا في مجالات التعليم والرعاية الصحية وأنظمة ERP وأرشفة المستندات. أصمم أنظمة تصمد تحت الضغط: مسارات Webhook لا تتكرر أحداثها، ومخططات MySQL مضبوطة الأداء (واجهات API أسرع بنسبة 35% وزمن استعلامات أقل بنسبة 40%)، وتكاملات دفع مع ماي فاتورة وتابي وتمارا.

المهارات التقنية

الأنظمة الخلفية
PHP، Laravel، Livewire، Filament، تصميم RESTful API، المعمارية المبنية على الأحداث، الطوابير والمهام الخلفية، CodeIgniter
الواجهات الأمامية
React، Inertia.js، Vue.js، TypeScript، JavaScript (ES6+)، Tailwind CSS، GSAP، إدارة الحالة
سلة وزد والتجارة الإلكترونية
تطوير تطبيقات متجر تطبيقات سلة، واجهات سلة البرمجية (REST APIs)، محرك قوالب Twilight، الربط مع زد، مزامنة Webhooks، حقن السكربتات، أدوات زيادة المبيعات
المعمارية والبيانات
معمارية متعددة المستأجرين (قاعدة بيانات واحدة أو قاعدة لكل مستأجر)، تحسين أداء MySQL، الفهرسة وضبط الاستعلامات، التخزين المؤقت بـ Redis، مسارات معالجة Idempotent
المدفوعات
ماي فاتورة (MyFatoorah)، تابي (Tabby)، تمارا (Tamara)، الدفع بالتقسيط والفوترة غير المتزامنة، الفوترة الإلكترونية ZATCA
السحابة والأدوات
AWS (EC2, S3)، Linux، Docker، Git/GitHub، مسارات CI
